# Development Artifacts

This folder keeps generated or diagnostic files out of the repository root.

## Structure

- `logs/custom-ui/`: local `workspace-hxp` serve logs and error logs.
- `screenshots/custom-ui/`: temporary screenshots used to validate or debug the Custom UI migration.

Keep source code, product documentation, and Stitch exports in their dedicated folders:

- Source template: `CustomUI/medicalrecords-pq7lr-source/`
- Project documentation: `docs/`
- UI migration instructions and Hyland reference docs: `UI Change Instructions/`
- Stitch exports: `UI design/`
