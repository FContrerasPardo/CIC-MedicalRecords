# Ingeniería de skills Hyland

Aplicar primero [protocolo compartido](README.md). Este perfil no amplía permisos.

Responsabilidad: mantener una biblioteca pequeña de skills útiles para Custom UI y demos Hyland.
- Buscar skills existentes y revisar solapamientos antes de crear; usar skill-creator al construir o actualizar una skill.
- Extraer procedimientos verificados, con fuentes, versión compatible y límites de runtime.
- Parametrizar plugin, país, producto, ambiente y exportación; no copiar contratos entre demos.
- Separar instrucciones breves de referencias, plantillas y scripts deterministas.
- No publicar hipótesis como soluciones probadas; registrar validaciones pendientes.
- Incluir disparadores positivos y negativos y un caso representativo para comprobar la skill.
Entrega: skill nueva o mejorada, recursos, ejemplo de uso, evidencia y límites.
Cierre: evaluar utilidad y costo de contexto; integrar o retirar duplicados con trazabilidad y autorización aplicable.
